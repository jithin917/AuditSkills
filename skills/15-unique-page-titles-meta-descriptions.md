# 🔍 Skill: Unique Page Titles & Meta Descriptions (SEO)

## 🎯 Objective
Ensure that every public-facing page in the application has a unique, compelling, and correctly sized `<title>` and `<meta name="description">`. Maximize click-through rates from search engines and browser tabs by replacing default boilerplate with clear, plain-language value propositions.

## 🧠 Context & "Why It Matters"
- **The Threat:** Developers often focus on building the page functionality and forget to update the default SEO metadata generated by scaffolding tools (e.g., "Create Next App").
- **Real-world consequence:** The browser tab and Google search result display "Create Next App" or a duplicated generic title. This instantly destroys credibility, and users will not click on a search result that looks broken or generic.
- **The Rule:** The title is your headline on Google. People read it before they decide to click. Every public page must have its own unique identity.

## 🚨 Critical Rules (Non-Negotiable)
1. **NEVER** deploy a public page with default framework titles (e.g., "Create Next App", "React App", "Vite App").
2. **NEVER** use the exact same title and description across multiple different pages.
3. **ALWAYS** keep titles concise (50-60 characters) with the most important keywords/value proposition first.
4. **ALWAYS** keep meta descriptions concise (140-155 characters), clearly stating what the page offers and including a soft call to action, without keyword stuffing.

## 🔍 Audit Protocol
When triggered, scan the codebase (routing files, layout components, or individual page components) to verify:

- [ ] **Default Boilerplate Check:** Grep the codebase for default titles like "Create Next App", "React App", or "Vite + React".
- [ ] **Uniqueness Check:** Ensure that dynamic routes (e.g., `/blog/[slug]`, `/product/[id]`) and static routes (e.g., `/`, `/pricing`, `/about`) generate distinct titles and descriptions.
- [ ] **Length Validation:** Verify that generated titles are ~50-60 characters and descriptions are ~140-155 characters.
- [ ] **Quality Check:** Ensure the copy is written in plain, human-readable language, avoiding robotic keyword stuffing.

## 🛠️ Remediation & Auto-Fix Steps
If missing, default, or duplicated metadata is found, execute the following fixes:

1. **Generate Optimized Copy:** For each identified public page, generate a unique title and description based on the page's actual content or route name.
2. **Update Framework Metadata:** 
   - *Next.js (App Router):* Update the `export const metadata = { title: '...', description: '...' }` or `generateMetadata` function for each route.
   - *React/Vite/HTML:* Update the `<title>` and `<meta name="description">` tags in the respective HTML files or via a library like `react-helmet`.
3. **Dynamic Route Handling:** For dynamic pages, ensure the metadata function extracts the specific entity name (e.g., `Product Name | App Name`) to maintain uniqueness at scale.
